3. Logical Operators
10 Questions
1. Write a program to check whether a number is greater than 10 and less than 50.
2. Write a program to check whether a number is divisible by both 3 and 5.
3. Write a program to check whether a number is divisible by either 4 or 6.
4. Write a program to check whether a person is eligible for a driving licence based on age and possession of a learner's licence.
5. Write a program to check whether a number is not within the range 20 to 40.
6. Write a program to check whether a year is a leap year using logical operators.
7. Write a program to check whether three given sides can form a valid triangle.
8. Write a program to check whether a character is a vowel using logical operators.
9. Write a program to check whether a student passes an examination if all three subject marks are at least 35.
10. Write a program to check whether a user can log in when the username and password are correct and the account is not blocked.
