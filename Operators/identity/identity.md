Identity Operators
10 Questions
1. Create two variables referencing the same list and check whether they refer to the same object.
2. Create two separate lists with identical elements and compare them using is and ==.
3. Write a program to check whether a variable refers to None.
4. Write a program to check whether a variable does not refer to None.
5. Create two variables referencing the same dictionary and check their identity.
6. Create two separate dictionaries containing identical key-value pairs and check whether they are the same object.
7. Create a list and assign it to another variable. Modify the list through the second variable and check whether both variables still reference the same object.
8. Create a list and its shallow copy. Check whether the original list and copied list have the same identity.
9. Create two variables referencing the same nested list. Check the identity of both outer lists and their inner lists.
10. Create two separate nested lists containing identical values. Compare the identities of their outer lists and corresponding inner lists.
